# Intro-Aud
The public Enter Campus click calls HTMLMediaElement.play() synchronously and navigates to /enter using the persistent provider. The original MP3 is local, SHA-256 verified, 102.687313 s. The caption engine validates the asset hash and word times and uses currentTime plus binary search; no fixed typing delay. The existing account chooser appears only after the ended event, a signed server completion acknowledgement, and a short transition. A blocked or interrupted recording is recoverable using retry/resume, without skip controls. Returning authenticated users or a valid 30-day completion cookie can proceed without replay. The signed HttpOnly token enforces elapsed time and version, not proof of listening; rate limits use existing Firestore rate limiter. Verified signup/login persists completion to the existing user's private record, idempotently. Existing direct login/register links and auth API behavior remain unchanged to preserve referral links, password reset and account access; this is an onboarding UX gate, not an authentication security boundary. No BugBoy illustration was attached in this request; the scene uses the supplied campus background and a neutral audio icon, not an invented mascot. Caption alignment is produced once by the development-only workflow, not at runtime; missing/invalid captions fail closed with retry rather than fabricated words. Real physical device volume, live Firebase OTP delivery and actual listening are not guaranteed. No R2/media authorization change. The original MP3 was transferred using a temporary Drive copy.
