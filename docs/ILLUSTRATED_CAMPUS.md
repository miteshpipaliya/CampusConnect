# Illustrated campus (prouiux)
- Public / shows the supplied evening illustration, including its original typography. The actual Enter Campus link is placed over the printed CTA. Narrow/portrait screens use the supplied daytime art and live responsive typography; no stretched desktop screenshot. The original artwork is not regenerated. The visible progress label is corrected to two entry stages.
- /enter offers registration and login. An authenticated session can continue to /home. /register and /login retain the existing CampusAuth requestOtp, verifyOtp, finishOtp and loginPassword API contracts; no Firebase, Firestore, cookie, referral or authorization code is changed. The OTP resend timer now re-renders while waiting. No real OTP is sent by tests.
- /home adds the campus hero only on the main Home section and preserves the existing feed/stories/composer and social shell. Links use existing Explore, Connections suggestions, community feed, Messages, Notifications, Profile, Settings and referral routes. Events opens the existing authenticated #events hashtag feed; this is not an event calendar or registration backend. Guide is a real navigation disclosure, not an AI assistant.
- No BugBoy asset, individual foliage/cloud layers or student character assets were supplied. No substitutions or invented architecture. The flattened campus illustration supports a restrained CSS camera drift, not separately animated leaves/clouds. Reduced motion disables it.
- Images are optimized WebP (1672 x 941 each), same supplied composition. Temporary Drive copies were used to transfer the two WebP blobs.
- Production remains on main until separately approved.
